## What the critic caught (specific, honest)

This run is a live LLM executor, so the interesting part is where the governance disagreed with the
agent. None of these reached the report as fact:

1. **The live agent failed to anchor the high-volume parses.** `$MFT` and USN-journal tasks
   (TASK-016/017/019) returned no parseable anchored claims on attempt 1 (`agent_produced_no_claims` /
   `agent_output_not_parseable_as_claims`). The critic forced a retry with tightened criteria; attempt 2
   still failed; the tasks were escalated and **quarantined**. So `parse_mft_filesystem` (22 calls) and
   `parse_usnjrnl` (15 calls) executed, but produced **zero promoted findings** - the system refused to
   emit unsupported claims rather than guess. This is the genuine "the critic caught the agent" case, and
   the honest cost: this run has no MFT/USN findings (the deterministic floor surfaces those mechanically;
   the live agent is more autonomous but less reliable on large tabular output).
2. **Over-broad memory claims, downgraded and contradicted.** The agent's `analyze_memory` output flagged
   "Possible injected code" in system processes (SearchApp, MsMpEng, dllhost, Teams, ...). Duplicated
   SearchApp (PID 8312/19436) claims tripped the contradiction rule (5 contradictions) and were
   confidence-downgraded (0.50 -> 0.25). None are asserted as malware - they are low-confidence,
   review-only `malfind` RWX leads in system processes.
3. **A real tool failure, surfaced not hidden.** `TOOL-050` (`analyze_prefetch` on
   `WMIPRVSE.EXE-E8B8DD29.pf`) returned `parse_error`; the one claim anchored to it is labelled
   "anchored to a tool call that did not fully succeed - verify manually."
4. **Injection-scanner over-trigger (known limitation).** Of the 11,628 injection alerts, 11,625 are the
   `base64_blob` signature firing on base64-like SHA-256 hash fragments in tool output - false positives.
   This is fail-safe (it over-flags, routing to human review, never under-flags), but noisy; tightening the
   base64 heuristic is on the roadmap.
